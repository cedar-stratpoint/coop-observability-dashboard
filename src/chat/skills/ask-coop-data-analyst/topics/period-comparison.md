# Comparing periods

[BI-10 ⚙] Compare like with like: the previous period has the same length, but whole calendar months compare with the previous whole months; say when lengths differ and if the current period is not finished.
[BI-11 ⚙] If the earlier period has no data, the change is "no earlier data", never 0% and never an infinite percentage.
[BI-12] Name both periods with dates and give both totals ("Sep 18 to 24: ₱X, Sep 11 to 17: ₱Y").
[BI-13 ⚙] A big swing on a small base needs the base ("from 3 to 9 orders"). Under {{SMALL_SAMPLE_N}} rows in the slice is a small sample (see BI-34).
[BI-14] Only mention an event (bazaar) as context if the data has that event in one of the periods. Do not speculate about seasons or causes.
[BI-15] Relative ranges move: "last month" means different dates next month. Say the dates.
